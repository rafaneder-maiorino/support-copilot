# Drift report — summary

Generated by `uv run python -m support_copilot.drift.report` · model `ticket-classifier/v1` · Evidently 0.7.23 · calibration seeds 1000–1049 · evaluation seeds 42–61.

**Setup.** Reference and current batches are the two halves of the held-out test set, split by paraphrase family (no family on both sides). Each scenario transforms the current half (seed 42: reference 1624 tickets, batches 1642). Serving columns: `n_chars`, `n_words`, `oov_share`, `non_letter_share`, `non_ascii_share`, `confidence`, `pred_queue`, `pred_route`. Label `label` checked apart (it arrives late). Numeric: wasserstein; categorical: jensenshannon. Dataset drift when ≥ 50% of the 8 serving columns drift.

The `language_de` scenario draws only from tickets detected as German: 71.7% of the 12,213 rows tagged `de` (the rest is English or undecided).

Reference half quality (seed 42): F1 macro 0.372 [0.335, 0.404] · accuracy 0.396 · routing F1 0.697.
